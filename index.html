about-me/

Python Django REST APIs PostgreSQL JavaScript Docker

Backend Python/Django is my core - API design, data modeling, and application structure. I build full-stack platforms for real clients: custom CMS-driven sites and geospatial pipelines (DXF/KML/KMZ/TXT/JSON), where bad input is the norm and predictable output is the whole job, so I design validation first and fail loudly rather than silently.

Before software, I spent a decade as a licensed surveying and geoinformatics engineer. That background is why I build this way: I used to do these workflows by hand, so I know exactly where the data goes wrong and what the field actually needs.

I care most about systems that stay maintainable after launch: reusable patterns over one-off code, and interfaces that make user error hard.
